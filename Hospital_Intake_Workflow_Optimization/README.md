# 🔄 Process Improvement Lifecycle

The project follows a structured workflow-optimization lifecycle:

```text
Assess Current State
        ↓
Identify Bottlenecks
        ↓
Design To-Be Workflow
        ↓
Configure & Train
        ↓
Pilot & Validate
        ↓
Roll Out
        ↓
Stabilize & Close
```

### 1️⃣ Assess Current State

- Observe intake workflow
- Document As-Is process
- Define operational KPIs
- Gather stakeholder input
- Identify pain points

### 2️⃣ Identify Bottlenecks

- Duplicate data entry

- Clinical handoff gaps

### 3️⃣ Design To-Be Workflow

- Digital pre-registration
- Real-time field validation

- Standardized readiness checklist
- Reduced duplicate entry

### 4️⃣ Configure & Train

- Digital intake configuration
- Workflow rules
- Staff training
- Job aids
- Operational procedures

### 5️⃣ Pilot & Validate

- Pilot launch
- Daily KPI monitoring
- Defect tracking
- Exception analysis
- Readiness review

### 6️⃣ Roll Out

- Phased department rollout
- Change communication
- Adoption support
- Issue management

### 7️⃣ Stabilize & Close

- KPI validation
- Risk closure
- Budget reconciliation
- Lessons learned
- Executive closeout

# 🧮 Excel Formulas Demonstrated

### Registration-Time Reduction

```excel
=IFERROR((C2-D2)/C2,0)
```

Measures improvement from baseline registration time to current performance.

### Days to Due

```excel
=IF(F2="Complete",0,H2-TODAY())
```

Calculates remaining days for project tasks.

### RAG Task Health

```excel
=IF(F2="Complete","Green",IF(H2<TODAY(),"Red",IF(H2-TODAY()<=3,"Amber","Green")))
```

Automatically identifies schedule health.

### RAID Risk Score

```excel
=D2*E2
```

Calculates:

**Impact × Probability**

### Milestone Variance

```excel
=IF(C2="","",C2-B2)
```

Measures actual milestone performance against the baseline date.

### Budget Variance

```excel
=B2-C2
```

Calculates favorable or unfavorable project cost variance.

### Task Completion

```excel
=COUNTIF('Task Tracker'!F2:F13,"Complete")/COUNTA('Task Tracker'!A2:A13)
```

Calculates overall project completion.

# ⚠️ RAID Management

The project includes structured management of:

- **Risks**
- **Assumptions**
- **Issues**
- **Dependencies**

### 💻 Digital Adoption Risk

**Risk:** Digital intake adoption may be lower in Emergency Intake.

**Mitigation:** Add an assisted digital-intake station and standardized staff script.

### 💳 Eligibility Backlog Risk

**Risk:** Moving verification upstream could create a pre-arrival backlog.

**Mitigation:** Establish queue thresholds and backup coverage.

### 🔄 Workflow Consistency Risk

**Risk:** Departments may implement the optimized workflow differently.

**Mitigation:** Standard work, training, and audit checklists.

### 🐞 Field Mapping Issue

**Issue:** Pilot testing exposed duplicate guarantor-field mapping.

**Resolution:** Correct the field mapping and regression-test all intake pathways.

### 👩‍⚕️ Clinical Approval Dependency

**Dependency:** Clinical leadership approval was required before full rollout.

**Response:** Conduct formal readiness review using pilot results.

# 🔍 SQL Healthcare Operations Analytics

**File:**

`intake_analysis.sql`

The SQL analysis demonstrates lightweight operational analytics including:

- Weekly patient volume
- Registration-time trends
- Wait-time trends
- Digital-form adoption
- Data error rates
- Issue trends
- Process-improvement measurement

Example:

```sql
SELECT
    week,
    patients_processed,
    avg_registration_min,
    avg_wait_min,
    ROUND(digital_form_rate * 100, 1) AS digital_form_pct,
    ROUND(data_error_rate * 100, 1) AS data_error_pct,
    patient_satisfaction
FROM intake_metrics
ORDER BY week;
```
