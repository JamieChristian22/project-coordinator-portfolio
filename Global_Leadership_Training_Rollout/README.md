# 🧮 Excel Formulas Demonstrated

Examples include:

```excel
=IFERROR(D2/C2,0)
```

Calculates attendance rate.

```excel
=IFERROR(E2/D2,0)
```

Calculates completion rate.

```excel
=D2*E2
```

Calculates RAID risk score using:

**Impact × Probability**

```excel
=IF(F2="Complete",0,H2-TODAY())
```

Calculates days remaining until a task deadline.

```excel
=IF(F2="Complete","Green",IF(H2<TODAY(),"Red",IF(H2-TODAY()<=3,"Amber","Green")))
```

Automatically assigns task health using **RAG status**.

```excel
=IF(C2="","",C2-B2)
```

Calculates milestone schedule variance.

```excel
=B2-C2
```

Calculates budget variance.

```excel
=COUNTIF('Task Tracker'!F2:F13,"Complete")/COUNTA('Task Tracker'!A2:A13)
```

Calculates overall project task completion.

# ⚠️ RAID Management

The project includes structured management of:

- **Risks**
- **Assumptions**
- **Issues**
- **Dependencies**

Example items include:

### 🌐 Time-Zone Attendance Risk

**Risk:** Regional time-zone conflicts could reduce attendance.

**Mitigation:** Provide multiple delivery windows and recorded options.

### 🌍 Localization Delay Risk

**Risk:** Regional content review could delay EMEA or APAC delivery.

**Mitigation:** Parallelize translation reviews and prioritize critical content.

### 🎤 Facilitator Availability Risk

**Risk:** Facilitator availability could create session gaps.

**Mitigation:** Maintain a trained backup facilitator pool.

### 🖥️ LMS Enrollment Issue

**Issue:** Enrollment logic omitted a manager population.

**Resolution:** Correct enrollment logic and reconcile the participant population before launch.

# 🔍 SQL Program Analytics

**File:**

`program_analysis.sql`

SQL analysis demonstrates lightweight program reporting such as:

- Attendance trends
- Completion rates
- Satisfaction
- Weekly delivery volume
- Issue trends
- Program performance

Example:

```sql
SELECT
    week,
    registered,
    attended,
    completed,
    ROUND(attended * 100.0 / NULLIF(registered, 0), 1) AS attendance_pct,
    ROUND(completed * 100.0 / NULLIF(attended, 0), 1) AS completion_pct
FROM program_metrics
ORDER BY week;
```
